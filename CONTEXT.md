## PROJECT
Biofresh — restaurant web app. MERN stack, EJS templating, MVC architecture.

## CODE RULES
Simplest solution that works. Clarity over cleverness — junior dev should understand in 30s.
- Long readable names over short cryptic ones
- One function, one job, named after what it does
- No clever one-liners; split logic if it helps readability
- Vanilla-first: 5 lines of plain code beats a library import
- Comments: explain "why" above logical blocks, not obvious statements
